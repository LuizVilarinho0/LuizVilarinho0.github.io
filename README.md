# Luiz Vilarinho — Portfólio

Portfólio de e-commerce e tecnologia: React + TypeScript (Vite) no front e PHP no backend
(formulário com envio por e-mail e agenda de reuniões ligada ao Google Agenda).

- **Site:** https://luizvilarinho0.github.io
- **Rodar localmente:** `npm install` e `npm run dev`
- **Guia completo** (e-mail, Google Agenda, publicação na Hostinger): [LEIA-ME.md](LEIA-ME.md)

> No GitHub Pages o site roda em "modo estático" (sem PHP): o contato é enviado pelo FormSubmit e a
> agenda convida para marcar pelo WhatsApp/e-mail. Com hospedagem PHP, tudo funciona completo.
