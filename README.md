# Luiz Vilarinho — Portfólio

Portfólio de e-commerce e tecnologia: React + TypeScript (Vite) no front e PHP no backend
(formulário de contato com envio por e-mail).

- **Site:** https://luizvilarinho0.github.io
- **Rodar localmente:** `npm install` e `npm run dev`
- **Guia completo** (e-mail, publicação no GitHub Pages ou na Hostinger): [LEIA-ME.md](LEIA-ME.md)

> No GitHub Pages (sem PHP) o formulário de contato é enviado pelo FormSubmit. Em hospedagem com PHP,
> ele envia pelo seu próprio Gmail.
